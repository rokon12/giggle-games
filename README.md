# Giggle Games

Play at **https://rokon12.github.io/giggle-games/**.

Thirteen browser games: Pop, Munch, Sing, Peekaboo, Splat, Boom, Silly Face, Shapes, Drums, Tickle, Brush, Grow, and a two-player Three in a Row game.

## Run locally

Open `index.html` in a modern browser. The game includes its scripts and fonts, so no installation or build is required. Tap or click a game to start; use the sound button to mute or unmute.

## Publish updates

GitHub Pages serves the root of the `main` branch. Commit changes to `index.html` to update the live game. Keep `.nojekyll` in the repository so GitHub serves the bundled HTML without Jekyll processing.
